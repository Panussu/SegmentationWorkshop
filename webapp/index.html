❓ ทำไมในกราฟ ROC ถึงมีเส้นโค้งแค่ "เส้นเดียว" ไม่ได้มีสองเส้น?

เส้นโค้ง (Curve) จะเกิดขึ้นได้ก็ต่อเมื่อมี "คะแนนความน่าจะเป็นต่อเนื่อง (0.0 ถึง 1.0)" ซึ่งช่วยให้เราสามารถค่อยๆ เลื่อนค่า Threshold จาก 0 ถึง 1 แล้วคำนวณจุด (FPR, TPR) มาต่อกันจนเกิดเป็นเส้นโค้งได้

แต่กระบวนการ Morphology (After) กระทำบนภาพ Binary Mask ขาว-ดำ (มีแค่ 0 กับ 1 เท่านั้น) ไม่ได้ส่งคะแนนทศนิยมต่อเนื่องออกมา จึงไม่มีค่าตัวเลขให้เลื่อน Threshold อีกต่อไป ทำให้ผลลัพธ์ของ Morphology ปรากฏได้เป็นแค่ "จุดพิกัดเดี่ยวๆ (Operating Point)" จุดเดียวบนกราฟ ไม่สามารถสร้างเป็นเส้นโค้งที่สองได้ครับ

🔵 เส้นทึบสีน้ำเงิน คืออะไร?

คือ ROC Curve ของคะแนนความต่างสี (Color Distance Score) คำนวณจากทุกพิกเซล ยิ่งโค้งโป่งชิดมุมบนซ้ายมากเท่าไหร่ พื้นที่ใต้กราฟ (AUC) จะยิ่งเข้าใกล้ 1.0 แปลว่าระบบแยกแยะสีสัตว์ออกจากพื้นหลังได้ดีขึ้น

⚪ เส้นประสีเทา คืออะไร?

คือ เส้นเดาสุ่ม (Random Guess Baseline) เทียบเท่ากับการโยนเหรียญเดา (AUC = 0.50) เส้นสีน้ำเงินที่โป่งขึ้นเหนือเส้นประนี้ พิสูจน์ว่าระบบสีมีประสิทธิภาพดีกว่าการสุ่มเดาอย่างมีนัยสำคัญ

🟠 จุด Before กับ 🟢 จุด After คืออะไร?

คือ จุดทำงานจริง (Operating Points) ณ สถานะที่เราตัดสินใจใช้งาน:
• Before: ตัด Threshold = 0.40 ตรงๆ (FPR=0.461, TPR=0.789)
• After: นำไปขัดเกลาด้วย Morphology (FPR=0.429, TPR=0.783) จะเห็นว่าจุดขยับมา ทางซ้าย แปลว่า ลดอัตราการทายพื้นหลังผิดลงได้สำเร็จ!

Section 3

ระดับความสว่าง 0–255 และบทบาทในโปรเจกต์นี้

🎨 จำลองสเกลพิกเซล 0–255 (Grayscale Intensity)

ในคอมพิวเตอร์วิทัศน์ ค่าพิกเซล 8-bit จะมีค่าตั้งแต่ 0 ถึง 255:

Value: 128 / 255
0 (มืดสุด / ดำสนิท) 255 (สว่างสุด / ขาวสนิท)
0 (Pure Black) Background (พื้นหลัง)
128 (Mid Gray) Trimap 3 (ขอบที่ไม่แน่นอน)
255 (Pure White) Pet Foreground (ตัวสัตว์)

🧪 ทำไมโปรเจกต์ถึงใช้ระบบสี CIELAB แทน RGB ธรรมดา?

ในระบบ RGB ระยะห่างของตัวเลขไม่ได้สอดคล้องกับความรู้สึกของตามนุษย์ (เช่น แสงไฟเปลี่ยนเพียงนิดเดียว ค่า RGB จะกระโดดไปไกลมาก)

L* (Lightness) ความสว่าง (0 = มืดสุด, 100 = ขาวสุด)
a* (Green ➔ Red) แกนเฉดสีเขียวถึงสีแดง
b* (Blue ➔ Yellow) แกนเฉดสีน้ำเงินถึงสีเหลือง
distance = √[(L - L_bg)² + (a - a_bg)² + (b - b_bg)²] score = distance / (distance + 50.0)

💡 ยิ่งสีต่างจากขอบภาพมาก: ค่า distance จะสูง $\rightarrow$ score เข้าใกล้ 1.0 $\rightarrow$ เมื่อ $\text{score} \ge 0.40$ ระบบจะเปลี่ยนพิกเซลนั้นเป็น 255 (ขาว/สัตว์) ทันที

สูตรคำนวณตัวชี้วัด (Metrics Formulas) คำนวณอย่างไร?

Accuracy (ความแม่นยำรวม) 62.25%
(TP + TN) / (TP + TN + FP + FN)

สัดส่วนพิกเซลที่ทำนายถูกทั้งหมด ไม่ว่าจะทายถูกว่าเป็นสัตว์หรือทายถูกว่าเป็นพื้นหลัง

Precision (ความแม่นยำเมื่อทายสัตว์) 46.22%
TP / (TP + FP)

ในบรรดาพิกเซลทั้งหมดที่โปรแกรมบอกว่าเป็นสัตว์ มีสัตว์อยู่จริงๆ กี่เปอร์เซ็นต์

Recall (ความไว / ความครอบคลุม) 78.93%
TP / (TP + FN)

ตัวสัตว์จริงทั้งหมดในภาพ โปรแกรมสามารถตรวจจับได้กี่เปอร์เซ็นต์

IoU (Intersection over Union) 0.4114
TP / (TP + FP + FN)

พื้นที่ทับซ้อนจริง หารด้วยพื้นที่รวมทั้งหมดของสัตว์จริงและส่วนที่ทำนาย (เป็นตัววัดมาตรฐานของ Segmentation)

Dice Coefficient (F1-Score) 0.5830
2TP / (2TP + FP + FN)

ค่าเฉลี่ยฮาร์โมนิกระหว่าง Precision และ Recall ให้ความสำคัญกับความทับซ้อนของตัวสัตว์
